7inOne - កំណត់ចំណាំដំឡើងកុំព្យូទ័រថ្មី
==========================================

គោលបំណង
--------
ប្រើ External SSD ដដែល ដើម្បីបន្តអភិវឌ្ឍ Project 7inOne នៅលើ Windows PC ផ្សេង។
ឯកសារដំឡើងនឹងពិនិត្យ និងដំឡើងកម្មវិធីដែលខ្វះ ដំឡើង Dependencies
បង្កើត CSS ពិនិត្យ Code ហើយបើកសេវាកម្មសម្រាប់សាកល្បង។

ឯកសារសំខាន់ៗ
-------------
ONE-CLICK-SETUP.bat   ឯកសារដំឡើង និងរៀបចំ PC ដោយស្វ័យប្រវត្តិ
START-AUTO-SYNC.bat   បើកការធ្វើសមកាលកម្ម Code ទៅ GitHub
START-LOCAL.bat       បើក Server 7inOne នៅលើកុំព្យូទ័រ
SETUP-PC.bat          ដំឡើង Dependencies ដោយដៃ (ជាជម្រើស)

មុនពេលប្រើលើ PC ផ្សេង
----------------------
1. Eject External SSD ដោយសុវត្ថិភាពពី PC ចាស់។
2. ដោត External SSD ទៅ PC ថ្មី។
3. បើក Folder Project 7inOne នៅលើ External SSD។
4. ពិនិត្យថាមានឯកសារ .env នៅក្នុង Folder ដើមរបស់ Project។
   កុំផ្ញើ ឬបង្ហាញខ្លឹមសារ .env ឱ្យអ្នកដទៃ និងកុំ Upload ទៅ GitHub។
5. បើក CMD នៅក្នុង Folder Project ហើយពិនិត្យការកែប្រែក្នុងម៉ាស៊ីន៖
      git status --short
6. បើមិនមានការកែប្រែដែលមិនទាន់ Sync ទេ សូមទាញយកការកែប្រែថ្មីពី GitHub៖
      git pull --ff-only origin main
   បើ Git បង្ហាញថាមានការកែប្រែក្នុងម៉ាស៊ីន ឬមាន Conflict សូមបញ្ឈប់សិន។
   កុំប្រើ reset, force-pull ឬលុបឯកសារ។ ត្រូវដោះស្រាយការកែប្រែឱ្យមានសុវត្ថិភាពជាមុន។

របៀបដំឡើងដោយចុចតែម្តង
-----------------------
ចុចពីរដងលើឯកសារ៖
    ONE-CLICK-SETUP.bat

វានឹងធ្វើការងារទាំងនេះ៖
- ពិនិត្យ និងដំឡើង Git for Windows តាម winget បើមិនទាន់មាន។
- ពិនិត្យ និងដំឡើង Node.js LTS ជំនាន់ 20 ឬថ្មីជាងនេះ បើមិនទាន់មាន។
- ពិនិត្យ និងដំឡើង Cloudflare Tunnel តាម winget បើអាចដំឡើងបាន។
- ដំណើរការ npm ci ដោយយោងតាម package-lock.json របស់ Project។
- បង្កើត frontend/public/marketplace/tailwind.css។
- ពិនិត្យ Syntax របស់ Code ដោយ npm run check។
- បើក Window សម្រាប់ GitHub Auto-Sync និង Cloudflare Tunnel។
- ចាប់ផ្តើម Local Server របស់ 7inOne។

បើ Windows សួរសុំសិទ្ធិដំឡើងកម្មវិធី សូមពិនិត្យមុនចុចអនុញ្ញាត។
ត្រូវមាន Internet និងសិទ្ធិដំឡើងកម្មវិធី។ បើដំឡើងរួចហើយ តែ CMD មិនទាន់ស្គាល់
កម្មវិធី សូមបិទ Window នោះ បើក CMD ថ្មី ហើយដំណើរការ ONE-CLICK-SETUP.bat ម្តងទៀត។

បន្ទាប់ពីដំឡើងរួច
-----------------
- URL សម្រាប់ប្រើនៅក្នុង PC៖ http://localhost:10000
- Cloudflare Tunnel នឹងបង្ហាញ HTTPS URL ដែលបញ្ចប់ដោយ .trycloudflare.com។
- ទុក Window Auto-Sync, Tunnel និង Local Server ឱ្យដំណើរការជាប់។
- Cloudflare Quick Tunnel ប្រើ URL បណ្ដោះអាសន្ន ហើយអាចប្តូរពេលបង្កើត Tunnel ថ្មី។
- អ្នកដែលមាន URL បណ្ដោះអាសន្នអាចចូលមើល Website បាន។ កុំបង្ហាញមុខងារ Admin
  ឬទិន្នន័យអ្នកប្រើប្រាស់ពិតប្រាកដក្នុងអំឡុងពេលសាកល្បង។
- បិទ Window Tunnel នឹងបញ្ឈប់ការចូលពីខាងក្រៅ។ បិទ Server នឹងធ្វើឱ្យ App ឈប់ដំណើរការ។
- បន្តកែ Code នៅលើ External SSD នេះ។ Auto-Sync នឹងតាមដានការកែប្រែ
  ហើយ Commit និង Push ទៅ GitHub main បន្ទាប់ពីការកែប្រែឈប់សិន។

ចំណុចសុវត្ថិភាពសំខាន់ៗ
---------------------
- ប្រើ External SSD ដដែល។ មិនចាំបាច់ Clone Project ជាច្បាប់ទីពីរទេ។
- កុំកែ Project ដដែលពី PC ពីរក្នុងពេលតែមួយ។
- Eject External SSD ដោយសុវត្ថិភាព មុនយកទៅ PC ផ្សេង។
- កុំ Commit ឬ Upload .env, ពាក្យសម្ងាត់, Private Key ឬ Secret ទៅ GitHub។
- កុំប្រើ git push --force, git reset --hard ឬពាក្យបញ្ជាដែលអាចលុបទិន្នន័យ។
- បើ Auto-Sync ឈប់ដោយសារតែ GitHub មាន Commit ថ្មីជាង សូមដោះស្រាយឱ្យបានត្រឹមត្រូវមុនបន្ត។
- រក្សា Supabase Project និងទិន្នន័យចាស់ដដែល។ កុំបង្កើត Project ថ្មីជំនួស។
- កុំ Deploy ទៅ Render លុះត្រាតែមានការស្នើសុំជាក់លាក់។

ដោះស្រាយបញ្ហា
--------------
បើ Setup បរាជ័យ៖
1. អាន Error ដែលបង្ហាញនៅក្នុង Window។
2. កុំលុបឯកសារ Project ឬ .env។
3. ពិនិត្យ Internet និង winget ដោយប្រើ៖
      winget --version
4. ពិនិត្យកម្មវិធីដែលបានដំឡើង៖
      git --version
      node --version
      npm --version
      cloudflared --version
5. ផ្ញើសារ Error មកសុំជំនួយ (កុំផ្ញើខ្លឹមសារ .env)។
